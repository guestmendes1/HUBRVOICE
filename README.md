# HubBR — Conecte. Converse. Compartilhe.

Plataforma brasileira de comunicação inspirada em apps modernos, com foco em **grupos, canais e chamadas de vídeo/áudio usando Google Meet API**.

## ✨ Funcionalidades

### 🏠 Grupos & Canais
- Criar e gerenciar grupos com ícones personalizados
- Canais de texto (#) e de voz (🔊)
- Sistema de permissões (Dono, Admin, Moderador, Membro)
- Sistema de convites com links compartilháveis

### 💬 Chat em Tempo Real
- Mensagens com avatar, nome de exibição e timestamp
- Editar e excluir mensagens
- Responder a mensagens
- Emojis rápidos
- Indicador "digitando..."
- Scroll automático

### 📞 Chamadas de Vídeo/Áudio
- Criar chamadas em canais de voz
- Grid de participantes com vídeo/avatar
- Controles: Microfone, Câmera, Compartilhar Tela
- Indicador de quem está falando
- Duração da chamada em tempo real
- **Integração com Google Meet API** (quando as credenciais estiverem configuradas)

### 🔐 Autenticação
- Login com Google OAuth 2.0
- Perfil com nome de exibição, bio e status
- Status: Online, Ausente, Ocupado, Invisível

### 🎨 Design
- Interface dark mode premium
- Design minimalista e moderno
- Animações suaves
- **100% responsivo** (Desktop, Tablet, Celular)

## 📦 Setup para Desenvolvimento

### 1. Instale as dependências

```bash
cd hubbr
npm install
```

### 2. Configure as variáveis de ambiente

Copie `.env.example` para `.env`:

```bash
cp .env.example .env
```

Edite o `.env` com suas credenciais:

```env
DATABASE_URL="postgresql://user:password@localhost:5432/hubbr?schema=public"
GOOGLE_CLIENT_ID=seu_client_id
GOOGLE_CLIENT_SECRET=seu_client_secret
GOOGLE_REDIRECT_URI=http://localhost:3000/api/auth/callback/google
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=gere_com_openssl_rand_hex_32
```

> ⚠️ **IMPORTANTE**: Nunca coloque `GOOGLE_CLIENT_SECRET` no frontend!

### 3. Configure o banco de dados PostgreSQL

Certifique-se de ter o PostgreSQL instalado e rodando, depois:

```bash
npx prisma migrate dev --name init
npx prisma generate
npx tsx prisma/seed.ts  # dados demo (opcional)
```

### 4. Execute o projeto

```bash
npm run dev
```

Acesse: [http://localhost:3000](http://localhost:3000)

## 🚢 Deploy em Produção (Railway)

### Pré-requisitos
- Conta no [Railway](https://railway.app/)
- Projeto no [Google Cloud Console](https://console.cloud.google.com/) com OAuth 2.0 configurado

### Passo a passo

1. **Crie um novo projeto no Railway** e conecte o repositório GitHub

2. **Adicione um banco PostgreSQL** no Railway:
   - No painel do projeto, clique em **"+ New"** → **"Database"** → **"PostgreSQL"**
   - Railway cria automaticamente a variável `DATABASE_URL`

3. **Configure as variáveis de ambiente** no Railway:
   ```
   DATABASE_URL=<auto-generated by Railway>
   NEXTAUTH_URL=https://seu-app.up.railway.app
   NEXTAUTH_SECRET=<gere-com-openssl-rand-hex-32>
   GOOGLE_CLIENT_ID=<seu-google-client-id>
   GOOGLE_CLIENT_SECRET=<seu-google-client-secret>
   GOOGLE_REDIRECT_URI=https://seu-app.up.railway.app/api/auth/callback/google
   ```

4. **Configure o Google Cloud Console**:
   - Adicione `https://seu-app.up.railway.app` como domínio autorizado
   - Adicione `https://seu-app.up.railway.app/api/auth/callback/google` como URI de redirecionamento autorizado

5. **Deploy automático**: Railway detecta o Next.js e executa automaticamente:
   ```
   npm install → prisma generate → prisma migrate deploy → next build → next start
   ```

### Variáveis de Ambiente

| Variável | Obrigatória | Descrição |
|---|---|---|
| `DATABASE_URL` | ✅ | URL de conexão PostgreSQL |
| `NEXTAUTH_URL` | ✅ | URL base da aplicação (ex: `https://app.up.railway.app`) |
| `NEXTAUTH_SECRET` | ✅ | Segredo para JWT (gere com `openssl rand -hex 32`) |
| `GOOGLE_CLIENT_ID` | ✅ | Client ID do Google OAuth |
| `GOOGLE_CLIENT_SECRET` | ✅ | Client Secret do Google OAuth |
| `GOOGLE_REDIRECT_URI` | ✅ | URI de callback do Google OAuth |
| `NEXT_PUBLIC_APP_NAME` | ❌ | Nome da aplicação (default: HubBR) |
| `NEXT_PUBLIC_APP_URL` | ❌ | URL pública da aplicação |

## 🔑 Google Meet API

A integração com Google Meet está preparada no backend. Para ativar:

1. Acesse o [Google Cloud Console](https://console.cloud.google.com/)
2. Crie um projeto ou selecione um existente
3. Ative a **Google Meet API**
4. Crie credenciais OAuth 2.0
5. Configure o `GOOGLE_CLIENT_ID` e `GOOGLE_CLIENT_SECRET` no `.env`
6. Autorize o escopo: `https://www.googleapis.com/auth/meetings.space.created`

**Endpoints da API REST do Meet:**
- `POST /v2/spaces` — Criar espaço de reunião
- `GET /v2/spaces/{spaceId}` — Informações da reunião
- `GET /v2/spaces/{spaceId}/participants` — Participantes
